# Hotel Booking Cancellation Prediction

Проект по машинному обучению для прогноза отмены бронирования в сети отелей.

Цель проекта:
- оценить риск отмены бронирования;
- сравнить несколько моделей классификации по `ROC-AUC`;
- оценить, как использование модели и депозитов влияет на финансовые потери отеля.

В ноутбуке выполнены:
- первичный анализ данных о бронированиях;
- подготовка числовых и категориальных признаков через `ColumnTransformer`;
- сравнение нескольких моделей классификации;
- проверка качества на тестовой выборке;
- расчет бизнес-эффекта от использования модели;
- анализ важности признаков и профиля клиента, склонного к отмене.

## Модели

В проекте сравниваются:
- Logistic Regression
- Random Forest
- HistGradientBoosting
- CatBoost
- LightGBM
- XGBoost

## Результаты

На кросс-валидации лучший результат показала модель **LightGBM**:
- ROC-AUC: **0.9357**

На тестовой выборке лучший ROC-AUC показала модель **RandomForest_depth12**:
- ROC-AUC: **0.8476**

Дополнительно:
- ROC-AUC на тестовой выборке для LightGBM: **0.8389**
- доля пойманных отмен: **62.04%**
- компенсация за счет депозитов: **9,689,472**
- чистый эффект после вычета 400 000: **9,289,472**

Наиболее важные признаки:
- `country`
- `lead_time`
- `total_of_special_requests`
- `customer_type`
- `required_car_parking_spaces`

2. Открыть ноутбук `notebooks/hotel_booking_cancellation.ipynb`
3. Запустить ячейки сверху вниз
